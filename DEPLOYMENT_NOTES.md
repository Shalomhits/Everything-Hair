# Deployment notes

1. Extract this project and open the `Everything Hair` folder itself in VS Code.
2. Start Live Server from `index.html`; the website is a static site and should be served from this project root.
3. Confirm all six pages and all interactions using `TEST_REPORT.md`.
4. Create or choose the final GitHub repository and enable GitHub Pages from the intended branch/folder.
5. Once the public URL is known, replace every `REPLACE-WITH-YOUR-PUBLISHED-DOMAIN` token in `robots.txt` and `sitemap.xml`.
6. Check the deployed page paths and sitemap URL in a browser. Submit sitemap in Google Search Console only if the business owner has access.
7. Confirm the business's approved contact email/social links, current inventory, pricing, delivery/returns policy and image permissions before presenting the site as a live retail storefront.

## Important
The proposal mentions `everythinghair.co.za`, but domain ownership and deployment are not confirmed. Do not assume the domain is active or controlled by the student.
